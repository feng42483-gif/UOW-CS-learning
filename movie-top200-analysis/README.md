# Movie Top 300 Data Analysis

A Python data analysis and visualization project based on Movie Top 300 data.

This project performs data cleaning, statistical analysis, and visualization using Pandas and Matplotlib.

---

## 📌 Project Introduction

This project analyzes Movie Top 300 data from multiple perspectives.

The main analysis includes:

- Number of movies by year
- Movie language distribution
- Movie genre distribution
- Movie score distribution

The project uses:

- Python
- Pandas
- Matplotlib
